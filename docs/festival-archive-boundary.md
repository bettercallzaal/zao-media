# Festival archive boundary

Festival raw media, working files, and permissioned assets are preserved in
the private Google Drive library and cataloged by the private
`bettercallzaal/zao-festivals-archive` repository.

This public repository remains the release catalog. Add a festival item here
only when its public destination and rights are clear. Link to public YouTube,
streaming, or deliberately public pages; never commit raw event footage,
private Drive links, contracts, credentials, or personal information.
